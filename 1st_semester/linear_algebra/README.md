# Σύντομη περιγραφή Μαθήματος

Επίλυση γραμμικών συστημάτων, ανηγμένη κλιμακωτή μορφή πίνακα, γραμμική ανεξαρτησία, πράξεις μεταξύ πινάκων (πολλαπλασιασμός, πρόσθεση), γραμμικέ απεικονίσεις και σχέση με πολλαπλασιασμό πινάκων, ιδιότητες και ορισμός οριζουσών, αντίστροφος πίνακας, διανυσματικοί χώροι και βάση διανυσματικών χώρων, μηδενοχώρος πίνακα, διαγωνιοποίηση και χαρακτηριστικό πολυώνυμο.
